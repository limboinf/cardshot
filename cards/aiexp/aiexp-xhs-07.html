把 AI 当陪练
别当枪手

作者开出的药方：主动保留摩擦，让 AI 回到“教练位”
❌ 别这样学
  • 学 Java 从 Spring Boot 开始
  • 学 JS 基础直接上 React
  • 学 CSS 一路 Tailwind
  • LLM 是终极泄漏抽象——抽象省的是干活时间，不是学习时间（Spolsky, 2002）
✓ 这样用 AI
  • 交互式文档，随问随答
  • 动态生成教程和练习
  • 苏格拉底式陪练——只提问不代写
  • 宾大实测：Tutor 模式练习效果 +127%
但 是 · 别忘了
AI 教练也会一本正经地胡说。它给的概念你验不了，就像它给的代码你审不动。官方文档、真人同事、亲手试错，三样一样都不能省
Kent Beck：写代码是巩固理解的最好方式——写得越多，懂得越深
最讽刺的真相：AI 编程工具里最有价值的学习时刻，恰恰是你几乎没让它写代码的时刻
核 心
走慢一点、难一点的路，才是 expertise 的唯一入口——没有快捷方式，只有代驾
