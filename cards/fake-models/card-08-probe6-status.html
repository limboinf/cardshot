/ 探针 06：官方宕机对照法

TRIGGER SCENARIO // 官方服务宕机对照 REAL-TIME
当 OpenAI 或 Anthropic 官方状态页（Status）全网大面积故障报警、官方 API 彻底不可访问时，去发起调用。
BASELINE 正规官方直连
同步报错 503 或超载
真实直连通道无法凭空响应，官方 API 瘫痪时，中转站必然同步返回 503、504 或 Overloaded 错误。
COUNTERFEIT 偷换便宜模型
官方挂了它却秒回
官方服务明明全面瘫痪，你的中转站却依然能秒回流畅对话——100% 触发了降级路由，偷换成了便宜模型或国产模型假冒！
照妖镜法则：官方都挂了你还能秒回，不是中转站技术有多神，而是你早就被换成了冒牌货。
耗时：5 秒 ｜ 适用：专打宣称“100% 官方纯直连”的中转平台LIMBO.PY
