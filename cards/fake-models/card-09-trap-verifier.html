/ 警惕所谓「验真网站」

很多人测中转站喜欢填进第三方的“在线防掺水检测站”。殊不知，裁判本身可能就是最大的黑产玩家：
01收钱办事的竞价排名
PAID RANKING
部分验真平台靠收取中转商“认证费”盈利。只要充值到位，把假模型洗成绿标正品；没交保护费的平台则被恶意标注异常。
02既当裁判，又卖中转
REFERRAL TRAP
自己做检测站吸纳流量，无论用户拿谁的接口来测，一律报“严重掺水”，反手弹窗推荐自己旗下的“官方独家保真”中转站。
03截留并偷盗 API Key
KEY HARVESTING
你在网页填入自己的 API Key，后台直接静默保存，用于该站自身的批量刷量甚至转卖黑市，造成余额被莫名盗刷。
自保铁律：绝不在任何第三方在线网页粘贴私钥！验真只用本地开源命令行工具或手动探针测试。
